# Saved experiments and reviewed artifacts

**Start with [refined-pilot/RESULTS.md](refined-pilot/RESULTS.md): the v0.2 study.**
These directories are deliberately included research evidence, not scratch runs.
Every observation is generated by the loopback lab; no production capture or
external target data is included.

| Directory | Role | Provenance |
|---|---|---|
| [refined-pilot](refined-pilot/README.md) | Current study: 60 development / 100 test runs | Collected with v0.2.0; six frozen policies |
| [refined-audit](refined-audit/AUDIT.md) | Diagnostic views of the current study | Derived from refined-pilot; no new independent runs |
| [pilot](pilot/README.md) | Historical baseline and regression fixture: 20 / 30 runs | Collected with v0.1.0; original report updated in v0.1.1 |
| [baseline-audit](baseline-audit/AUDIT.md) | Retrospective diagnosis of the historical pilot | Generated by v0.2.0; not fresh validation of refinements |

The v0.2.1 repository cleanup does not relabel these collection versions or
change their observations, models, metric files or existing figures. Historical
reports may contain superseded status text; use [VERIFICATION](../VERIFICATION.md)
for current validation status. Original files are preserved as recorded evidence.

## Artifact roles

| Files | Why they are retained |
|---|---|
| `manifest.json`, `plan.json`, `protocol.md` | Collection provenance and design; older runs may lack later fields |
| `observations/*.jsonl`, `features.*` | Raw stream measurements and derived model inputs |
| `model.json` | Frozen development-fitted rules |
| `metrics.*`, `predictions.csv`, `RESULTS.md`, `report.html` | Reproducible evaluation and human-readable results |
| Audit CSV/JSON/JSONL files | Traced alerts, development sensitivity and feature distributions |
| `figures/*.png`, `figures/*.svg` | Matplotlib outputs from saved metrics/features; PNG for viewing, SVG for reuse |

Audit reports repeat evaluation tables for standalone inspection. They are
alternative views of the same source experiments, not extra samples. Existing
figures have been reviewed for their source data and presentation; they do not
show production performance. HTML reports should be opened locally with their
`figures/` directory beside them.

Fresh runs belong in ignored `runs/` directories. They are excluded from source
releases until deliberately reviewed and promoted into `examples/`. Release
checksums are generated during packaging and are not maintained as a source file.
