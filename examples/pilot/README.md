# Historical pilot — preserved evidence

This is the original **v0.1.0 collection**, with a report generated by **v0.1.1**:
20 development runs and 30 held-out runs. It remains a regression fixture and
motivated the later refinement. Its original 63 files are preserved unchanged.

This directory is not the current headline study. See
[the v0.2 results](../refined-pilot/RESULTS.md) and
[current verification](../../VERIFICATION.md).

Historical statements about unimplemented sensitivity analysis describe the
status at that time. The current project includes a development-only audit;
[baseline-audit/AUDIT.md](../baseline-audit/AUDIT.md) explains it. Collection
versions and historical numbers are intentionally not rewritten.
